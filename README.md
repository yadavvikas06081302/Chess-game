# Chess Game

A responsive two-player Chess Game made with HTML, CSS and JavaScript.

## Features
- 8x8 chess board
- White vs Black turns
- Piece movement and captures
- Pawn promotion to Queen
- King capture ends the game
- Restart Game button
- Flip Board button
- Mobile responsive
- No external libraries

## Run
Open `index.html` in a browser.

## GitHub Pages
Upload all files to a GitHub repository, then:
Settings → Pages → Deploy from a branch → main → /(root) → Save.
